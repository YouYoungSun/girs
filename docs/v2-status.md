# v2 재개 기록

공통 1~3장과 다섯 개인 루트 각 7장, 21개 결말의 문체 수정을 소스에 반영했다. 생활 속 장난과 직접적인 호감 표현, 주인공도 먼저 다가가는 행동을 보강하고 선택하지 않은 경험·친구 경로의 연애 경험·약속 날짜와 물건 위치의 충돌을 정리했다. 독립 검수자가 원고를 재독해 지적한 발화 주체와 이동 방향, 선택문의 일정 표현과 산책 후속의 커피 구매도 수정했다. 인물별 사건과 말투를 대조한 관찰과 남은 결말 구성의 반복은 집필 지침에 기록했다. 새 수정본의 테스트·분기 감사·빌드·저장 호환 검증은 사용자가 나중에 진행하기로 한 후반 작업이다.

현재 원고 작업의 기준과 다음 시작 위치는 [집필 지침](writing-guide.md)을 따른다. 사용자 요청에 따라 테스트·빌드는 후반에 모아서 진행하며 화면 검증은 현재 작업 범위에서 제외됐다.

마지막 빌드는 v2.0.1 하린 2장 문체 시범 수정본이다. 당시 독립 검수 2명 및 수정 재확인, 전체 테스트 70개·빌드 통과, 수정 전 저장 위치 19개 복원을 확인했다. 그 이후 위의 전체 문체 수정은 소스에 반영한 상태이며 새 배포 파일은 만들지 않았다. 세부 사항과 전후 읽기본은 `reference-notes/harin-2-edit-review.md`를 따른다. 아래는 v2.0.0 구조 개편 당시 기록이다.

2026-11-11 재개. 한도 중단 당시 v2 엔진, 저장, 화면 초안만 남아 있었고 원고 모듈은 없었다. v1은 변경되지 않은 상태였다.

## 재개할 위치

원고: `src/v2/common.js`, `routes-a.js`(하린·세아), `routes-b.js`(유진·서윤), `routes-c.js`(이솔).
실행: `src/v2/story.js`가 원고를 그래프로 결합한다. `tests/v2-story.test.mjs`는 모든 결말을 탐색해 공개 엔진 API로 재생한다.
기본 진입점은 `src/v2/app.js`로 전환했다. `dist/release.json`과 HTML의 버전은 2.0.0이다. 배포·커밋은 수행하지 않았다.

## 최종 자동 검증

`npm.cmd test`: 69/69 통과. 기존 v1 회귀 57개와 v2 엔진·저장·전체 이야기·기본 진입점 검증 12개다.
`npm.cmd run build`: 통과. `git diff --check`: 오류 없음(CRLF 변환 안내만 출력).
`node scripts/v2-audit.mjs`: 1,111개 노드, 도달 가능한 21개 결말, 선택 상태 37,516개를 탐색했다. 실제 저장·선택·읽기 API로 모든 결말의 대표 경로를 재생했다. 도달 불가능한 원고 노드는 없다.

개인 루트의 대표 한 회차는 공통 포함 154~184개 읽기 화면, 약 22,665~25,063자다. 대표 감사 경로는 선택 13회이며 이솔의 일부 회복 경로는 14회다. 공통 우정은 더 짧은 별도 마무리다. 정확한 대표 경로와 선택은 `v2-path-audit.json`을 따른다.

## 독립 검수와 수정

집필에 참여하지 않은 세 검수자가 과거 대화 없이 원고와 실제 엔진 경로를 확인했다. 각 작성자가 수정하고, 같은 검수자가 지적한 재현 경로를 다시 확인했다.

- 이솔: 연애 후 친구 결말의 과거 부정 제거, 녹음 날짜 변경 경위, 첫 외부 작업 중복, 동등한 일정 선택의 숨은 등급 판정, 교훈식 해설 보정.
- 하린·세아: 지원서 마감과 제출일, Best 숙박·귀가계획 변경, 최신 회피 선택이 회복 분기를 건너뛰던 문제, 면접 결과 수신일, 유보 경로의 친구 확정 표현 보정.
- 유진·서윤: 연애 후 친구 결말의 경험 일치, 휴식 선택의 불필요한 불이익 제거, 공통에서 개인으로 넘어갈 때의 시간 역전, 회관 내부 막차 이동, 말 놓는 장면, 공사 중 회관 대신 도서관 전시로 연결.

날짜를 아직 확정하지 못한 연애의 Good과 실제 다음 데이트를 확정한 Best의 차이는 유지했다. 휴식·음악 취향·말을 많이 하는지 같은 생활 방식 자체를 정답으로 삼지는 않는다.

`review-*-independent.md`는 수정 전 문제 재현을 위한 감사 기록이다. 최신 원고가 그대로 오류를 유지하고 있다는 뜻은 아니다.

## 남은 확인과 한계

컴퓨터 사용 도구는 브라우저의 현재 URL을 충분히 확신할 수 없다는 이유로 조작을 중단했다. 따라서 실제 클릭·반응형 배치·이미지와 본문을 함께 보는 최종 화면 검증은 통과했다고 보고하지 않는다. 로컬 HTTP에서 v2 진입점·모듈·CSS가 제공되는 것은 테스트했다.

기존 CG 21장과 새 결말의 장소·행동은 원고·자산 설명 기준으로 맞췄으며 새 이미지는 생성하지 않았다. 실제 그림을 띄운 상태의 최종 대조는 위 화면 검증과 함께 남아 있다. 실제 사람의 60~90분 첫 독해도 아직 실측하지 않았다.
