# 하린 2장 문체 시범 수정 · v2.0.1

## 읽기본

- [수정 전 전체](harin-2-before.md)
- [수정 후 전체](harin-2-after.md)

이번 적용 범위는 하린 2장 「휴무」다. 다른 장과 다른 인물에 같은 문체를 일괄 적용하지 않았다. 전체 확대 전에 이 한 장의 읽는 맛을 비교하기 위한 시범이다. 추가 레퍼런스 열람은 이번 집필에서 필요하지 않다고 판단했으며, 앞서 확인한 공식 자료와 opening-study.md의 관찰 범위를 넘어 시청했다고 주장하지 않는다.

## 바꾼 흐름

1. 정류장에서 서로 기다리던 반응 → 하린이 빵집 조사 대신 함께 놀고 싶다고 말함.
2. 모래사장 사진과 아이스크림 → 데이트를 제안하거나 편히 쉬는 선택. 두 답변의 기존 사건 값 유지.
3. 하린이 고른 가게가 쉬는 날 → 다른 곳에서 점심 → 물가에서 놀고 함께 쉼.
4. 제과학교 이야기는 월요일 초안 부탁으로 간결하게 이어지고, 서울에 언제 가는지 먼저 묻는 하린의 반응이 드러남.
5. 버스의 자리와 사진을 통해 가까워진 거리를 의식함. 주인공도 먼저 좋다고 말함.
6. 외출 전 만들어둔 이름 빵 → 밤에 서로의 사진을 주고받고 다음에는 함께 찍기로 함.

감정의 의미를 서술자가 마무리하던 문장, 조사·계약식 말장난, 불명확한 글자 모양 묘사를 손봤다. 실제 행동과 말에 상대의 기대가 담기도록 했다.

## 독립 검수

과거 대화 없이 새 검수자 두 명이 각각 독자 관점과 앞뒤 문맥을 확인했다. 한 명은 수정 후 원고부터, 한 명은 수정 전후와 1·3장 연결을 읽었다.

수용한 지적:

- 주인공이 반복해서 실수하는 패턴: 쓰레기통 방향 실수와 버스의 연속 손동작 실수를 줄이고, 먼저 호감을 표현하는 행동을 추가했다.
- 데이트 답변 뒤 가게에 도착하는 연결: 공통 장면에서 하린이 가게를 직접 고르는 행동을 추가했다.
- 이미 함께 본 수첩: 처음 들킨 듯한 질문을 기억해준 데 대한 반응으로 바꿨다.
- 물수제비와 모래의 위치: 모래사장 물가에서 놀고 낮은 방파제 돌계단으로 이동하도록 했다. 신발의 모래를 터는 동작은 마지막 사진에도 연결된다.

수정 후 독자 검수자가 위 지적의 해소를 재확인했다. 대체로 장면이 잘 그려지고 하린 자신의 욕구가 보인다는 평가였으며, 강한 두근거림을 보증한 것은 아니다. 초반의 편안한 외출과 다음 만남을 기대하는 썸의 강도라는 평가도 남겼다.

## 진행·저장 검증

- 페이지 수·페이지 ID·선택 ID·선택 효과를 유지했다. 선택은 기존 1회 그대로다.
- 수정 전 생성한 2장 저장 위치 19개를 새 원고에서도 재생 검증했다.
- 하린 2장의 읽기 키만 새 variant로 구분한다. 새 원고를 기존 기독 스킵으로 통째로 지나치지 않게 하며 다른 장의 기독 기록은 유지한다.
- 전체 테스트 70개 및 빌드 통과. 21결말 도달·모든 원고 노드 도달 검증 통과.
- 사용자가 불필요하다고 한 실제 화면 검증은 수행하지 않았다. 사람의 실제 독해 시간도 실측하지 않았다.
