# AFTERGLOW v1 독립 검수 후 수정 기록

## 검수 방식과 범위
스토리·분기·CG를 나눈 독립 서브에이전트 세 명이 기존 구현을 읽기 전용으로 검수했다. 부모가 지적을 코드·최종 대사·실제 경로에 대조해 수정 계획을 만들고 세 명에게 계획의 반례 검수를 요청했다. 구현 후 다시 읽기 전용 검수를 요청했다. 마지막 두 발견은 아래의 자체 재현 검사로 검증했다.

30일, 개인 50개(각 10개), 단체 자유시간 10개, 연락 20개, 엔딩 21종은 유지한다. 정식 v1 저장 영역과 기존 기록은 삭제하지 않았다.

## 확인된 문제와 수정
- 세아6 친구/유보 뒤 세아7이 자동 데이트가 되던 문제: 관계에 맞춰 데이트/일반 식사를 나누고 실제 데이트에만 sea_noodle_date를 기록한다.
- 유진5가 제안만 하고 유진7이 외출 추억을 만들던 문제: 선택 반응에서 실제 둘/단체 외출을 보여주고 yujin_outing_pair/group을 나눠 기록한다. 과거의 외출을 소급해 데이트라고 확정하지 않는다.
- 유진9에서 친구로 지내자던 플레이어를 연애 강요자로 묘사하던 문제: 상태별 장면 전체와 선택·반응을 다시 작성했다. 친구 유지, 명시적 마음 변화, 개인 만남 종료를 구별한다.
- 서윤3 차 약속/이솔6 녹음 코스가 연애 의사로 판정되던 문제: 일상 meet 사실만 기록한다. 서윤9와 이솔9에서 명시적으로 연애 의사를 확인한다.
- 종료 뒤 공동 사건에서 다시 플러팅하던 문제: 개인·공동·단체·연락·회상·고백·관계 표시가 같은 상태 판정을 사용한다. 한 인물의 제한으로 다른 인물의 선택 근거와 로맨스까지 지워지지 않도록 혼합 사례도 검사한다.
- 미경험 연락의 질문과 답이 어긋나던 문제: 정확한 사건 ID와 미래 약속 표식으로 본문·선택·반응 전체를 교체한다. 유진 영화 회상은 유진4 경험을 확인한다.
- 본문과 장소 표기가 다르던 문제: 실제 장면 메타와 자유시간 목록 모두에 수정된 장소를 사용한다. 국숫집/영업 후 바/협동 게임 거실을 구분한다.

## 관계·엔딩 규칙
새 rel2 관계 표식은 기존의 잘못된 mutual/future 표식을 자동 승인하지 않는다. 기존 history는 보존하고, 새로 의미가 명확한 문답을 선택했을 때만 현재 연애 상태를 기록한다.

우선순위는 종료 > 친구 > 유보 > 연애 > 미확인이다. 새 상태로 바뀔 때 호환되지 않는 상태와 연애 후속 약속은 제거한다. 일상 만남 기록은 별도다.

- 명시적 종료: Bad.
- 명시적 친구: Normal. 친구를 고른 것 자체를 잘못으로 취급하지 않는다.
- 상호 연애 수락: 최소 Good. 서로 좋아한다고 말하고 약속한 뒤 점수가 낮다는 이유로 거절하는 결말은 나오지 않는다.
- Best: 연애 상태, 호감도 85 이상, 개인10 경험, 구체적인 다음 연애 약속.
- 미확인/유보: 점수가 높아도 Normal 상한. 친밀감 40 미만은 Bad.
- 마지막 고백의 말투는 과거 관계나 상대의 마음을 바꾸지 않는다. 친구였다가 마음이 바뀐 경우에는 그 맥락을 고백 전주에서 밝힌다.

## 이미지와 원본 보존
하린 Best는 앞치마 없이 손으로 한쪽이 탄 토스트를 맛보는 교정본으로 제작했다. assets/endings/v1/harin-best-toast.webp와 docs/ending-originals-v1/harin-best-toast.png를 사용한다. 이전 PNG/WebP는 보존하며 manifest의 previous에 출처를 남겼다. 변환 스크립트는 manifest에 기록된 실제 asset/original 경로를 따른다.

세아 Good의 첫/후속 데이트는 단순 장면 경험이 아니라 실제 sea_noodle_date 사실로 구분한다. CG 대체 설명은 등급에 대한 단정 대신 보이는 행동을 설명한다. 교정본은 CG 담당 서브에이전트도 실제 파일로 확인했다.

## 재현 검사
기존 분기·저장 검사 외에 tests/story-paths.test.mjs에서 실제 30일 선택을 통해 다음을 확인한다.
- 다섯 명의 Best와 명시적 종료 경로.
- 세아6 유보/친구 → 세아7 일반 식사 → 이후 연락·고백.
- 종료된 세아 → day21/day27 및 남은 개인 장면.
- 서윤 차 약속만/이솔 작업 코스만 → 높은 점수여도 연애 확정 금지.
- 유진 단체/둘 외출 → 사진·데이트 제안·친구 유지.
- 연애/친구/유보/종료 전환과 기존 미래 약속 제거.
- 선행 사건 유무·다른 선택·각 관계 상태에서 연락 질문/선택/반응의 일치.
- 한 인물은 종료, 다른 인물은 연애인 혼합 공동 장면에서 각자의 반응 유지.
- 상호 수락 후 낮은 점수로 30일을 마쳐도 Good 유지.

## 재검수 결과와 미검증 항목
서브에이전트들은 기존 핵심 P1(유진 역할 역전, 세아 자동 데이트, 일상 약속의 연애 오판)이 해결된 방향임을 확인했다. 추가로 보고된 두 문제, 즉 상호 수락 후 낮은 점수의 Normal 거절과 day13 쪽지 선택 근거 소실은 수정하고 회귀 검사를 추가했다.

검수자들의 마지막 추가 파일 읽기는 자동 승인 검토의 사용량 제한으로 중단됐다. 따라서 마지막 두 수정의 독립 재확인을 완료했다고 표시하지 않는다. 부모가 직접 재현 검사와 최종 테스트·구문 검사·빌드를 수행한다.

브라우저 도구의 Windows 실행 환경 초기화 오류로 실제 클릭·모바일 배치·확대 대화상자의 화면 검수는 미완료다. 이미지 파일은 직접 시각 검수했다.

## 후반 장면·문체 후속 수정

독립 검수에서 확인된 범위만 추가로 수정했다. 인물별 말투·관계 판정·이미지·30일 구조는 유지했다.

- late-scenes.js에서 하린10(주인공의 토스트), 유진10(협동 게임 보스 승리), 세아9(바 마감 후 휴식)을 제목·장소·본문·선택·반응 전체로 작성하고 routes.js에 연결했다. 초반 장면을 제목만 바꿔 재사용하지 않는다.
- 밤에도 방문할 수 있는 하린 장면의 점심/이른 아침 단정을 제거했다. 마지막 방문은 시간에 관계없이 만들 수 있는 토스트 간식으로 구성한다. 후일담의 아침은 별도 날짜임을 명시한다.
- Best는 고백에 대한 상대의 대답을 먼저 보여주고 후일담의 시점·장소를 명시한다. Good도 시간 전환을 붙였으며 엔딩 화면은 '마지막 대답과 그 후'로 표시한다.
- 하린의 마지막 주 연락은 실제 확정된 토요일 데이트를 기억한다. 가이드에는 호감도뿐 아니라 서로 확인한 마음과 다음 약속도 결말에 영향을 준다고 설명한다.
- 심판 부탁문의 조사, '마음에 답하다', 차별 대상을 잘못 가리키던 문장을 바로잡았다. 이미 대사로 전달한 사실을 재판정하는 설명과 Normal의 반복적인 교훈 문장은 덜어냈다.
- 사용자가 정한 단체방 이름에 '운영'이 없을 수 있으므로 이름을 바꾸는 대신 마지막 업무 공지를 내리는 반응으로 바꿨다.

추가 회귀 검사는 실제 30일 플레이에서 후반 세 장면의 내용, 밤의 지연 방문, 친구/종료 토스트 장면, 대답→시간 전환 순서, 확정 약속 연락을 확인한다. 최종 53개 검사 통과, JavaScript 구문 및 정적 빌드도 확인한다.

새 독립 검수자 두 명이 읽기 전용으로 수정 범위를 재확인했다. 실제 엔진 경로에서 세 late 장면과 비연애 continuation이 적용되고, 고백 답변과 후일담 전환이 연결됨을 확인했다. 문장 검수에서 추가 발견한 세아 Best의 기다린 주체 혼동과 이솔 Good의 게임센터 이동 중복도 수정한 뒤 최종 출력으로 재확인했다. 이 검수 범위에서 확실한 미해결 충돌은 보고되지 않았다. 실제 브라우저 클릭·모바일 배치 검수는 여전히 별도 미완료다.
