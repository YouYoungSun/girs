# 여름의 마지막 페이지 · AFTERGLOW v1

성인 다섯 명과 바닷가 달무리회관에서 한 달을 보내는 일상 로맨스 미연시입니다. 이름을 입력하고 입주하며, 자유롭게 여러 사람을 만나고 마지막 날 마음을 전합니다.

## 콘텐츠와 관계

- 공동 사건 30개, 개인 에피소드 50개(인물별 10개), 단체 자유시간 10개, 개인 연락 20개, 고백 장면 5개와 엔딩 21종.
- 한 번의 플레이: 공동 사건 30개, 자유시간 29개, 주별 연락 4개, 마지막 고백 또는 우정 엔딩.
- 하린은 생활 속 특별 대우와 이후 일정, 세아는 농담과 진심, 유진은 취미 친구와 연애의 구분, 서윤은 서로의 시간과 돌봄, 이솔은 함께할 약속으로 관계가 발전합니다.
- 개인 에피소드 해금일: 1·3·5·7·10·13·16·20·24·27일. 순서대로 제공되며 다른 사람을 만났다고 자동 감점하지 않습니다.
- 명시적으로 서로 연애 의사를 확인하면 최소 Good입니다. Best는 호감도 85 이상, 마지막 개인 에피소드와 실제로 정한 다음 약속이 필요합니다. 일상적인 차 약속·작업 동행은 연애 의사가 아닙니다. 친구로 지내기로 했다면 Normal이며, 아직 마음을 확인하지 않았다면 호감도 40 미만 Bad / 그 이상 Normal입니다. 개인적 만남을 끝내기로 한 경우는 해당 원인의 Bad입니다.
- 친구·유보·종료는 구분합니다. 일정을 바꾸거나 생각할 시간을 요청하는 것만으로 관계가 끝나지 않습니다. 종료는 이후 개인적인 만남을 원하지 않는다는 명시적 선택에서만 확정됩니다.

## 실행과 검증

Node.js 22 이상, 게임 실행에 외부 패키지는 필요하지 않습니다.

```sh
npm.cmd run dev
npm.cmd test
npm.cmd run build
```

로컬 주소는 http://localhost:3001 입니다. 빌드 결과는 dist/입니다. Vercel 설정은 Other / npm run build / dist 입니다.

## 저장과 이미지

정식 버전은 v1(1.0.0)입니다. 데이터는 `afterglow:release-v1:` localStorage에만 저장합니다. 자동저장, 책갈피 3개, JSON 내보내기·가져오기, 엔딩 서가를 지원합니다. 정식 v1 형식만 가져올 수 있고 개발 시안은 이전하거나 삭제하지 않습니다.

성인 캐릭터의 도트 디자인을 참조해 내장 image_gen으로 새 개인 엔딩 CG 20장을 제작하고 우정 CG 1장을 유지합니다. 게임용 WebP, 원본 PNG와 프롬프트를 보존합니다. 엔딩 이미지는 획득 이후에만 서가에 나타납니다. 모음 이미지에는 스포일러가 있습니다.

구현·검수 내용은 docs/revision.md, 상태별 실제 장면 목록은 docs/story-map.json을 참고하세요. 하린 Best 교정본은 assets/endings/v1/harin-best-toast.webp이며 기존 CG 원본도 보존합니다. 브라우저 도구의 실행 환경 오류로 실제 클릭·모바일 배치 검수는 미완료이며 자동 검사와 이미지 시각 검수는 별도로 진행했습니다.

최근 후속 수정에서는 후반 방문 세 장면을 실제 새 본문으로 연결하고, 밤 방문의 시간 표현·고백 답변과 후일담 전환·확정 약속 연락을 맞췄습니다. `src/life/late-scenes.js`가 후반 세 장면의 원본이며, 선택·본문까지 실제 경로로 검증합니다. 마지막 검수와 재현 범위는 `docs/revision.md`에 기록했습니다.

## 플레이어용 버전 표시

화면 상단에 현재 실행 중인 버전(v1.0.0)을 항상 표시합니다. 이후 출시 버전은 package.json의 version을 바꾸고 빌드·배포하면 됩니다. 개발 서버와 정적 빌드가 같은 설정에서 HTML 배지·버전 메타·release.json을 만듭니다. 저장 데이터의 형식 버전은 출시 표시와 별도로 관리합니다.

열려 있는 게임은 1분 간격 및 탭 복귀 때 release.json을 다시 확인합니다. 새 배포가 감지되면 현재 실행 버전 배지는 유지하고 새로고침 안내를 보여줍니다. 새 버전으로 다시 연 경우에는 한 번 버전 변경 안내를 보여줍니다. 버전 확인이 실패하거나 localStorage가 비활성화되어도 게임 진행은 막지 않습니다. 자동 새로고침은 하지 않습니다.
