# 여름의 마지막 페이지 · AFTERGLOW v2

**먼저 함께 생활하고, 마지막 날에 마음을 전하는 텍스트 미연시.**

해변 마을 달무리회관에서 기록집을 만들며 한 달을 보내는 편집자가 됩니다. 이름만 입력하고 입주합니다. 첫날에 히로인을 선택하거나 한 사람의 루트로 잠기지 않습니다.

## 새 진행 구조

1. **아침 / 공동 사건:** 매일 함께 보내는 장면. 식탁, 장보기, 공포영화, 바다, 야시장, 정전, 축제, 마지막 장터로 달력이 이어집니다.
2. **자유시간:** 1~29일에는 한 곳을 직접 골라 방문합니다. 단독 만남과 여러 사람이 함께하는 에피소드가 있고, 이미 본 사건은 반복되지 않습니다. 장소를 고르면 그날 자유시간을 사용합니다.
3. **개인 연락:** 7·14·21·28일 밤에는 먼저 연락할 사람을 고릅니다. 관계에 따라 메시지의 분위기가 달라집니다.
4. **마지막 선택:** 30일 장터가 끝난 뒤 다섯 명 중 누구에게나 고백할 수 있습니다. 최다 호감도 인물이 자동으로 선택되지 않습니다.
5. **대답:** 선택한 상대와 쌓은 호감도로 Best·Good·Normal·Bad가 결정됩니다. 고백 말투는 점수를 갑자기 올려주지 않습니다. 고백하지 않고 함께 저녁을 먹는 우정 엔딩도 있습니다.

전체 콘텐츠는 **공동 사건 30개 + 자유시간 45개(개인 35 / 단체 10) + 개인 연락 20개 + 고백 장면 5개 = 100개 장면**과 **엔딩 21종**입니다. 한 번의 플레이에서는 공동 사건 30개, 자유시간 29개, 연락 4개를 겪고 마지막 선택에 도착합니다. 모든 에피소드를 한 번에 볼 수는 없습니다.

대화 위주로 가볍게 읽으며, 함께 장난치고 취향을 알아가다 설레는 분위기입니다. 캐릭터마다 상담 문제를 해결해야만 연애가 되는 구조는 아닙니다. 과거 선택을 떠올리는 중간 대사와 특정 추억을 회수하는 후일담이 있습니다.

## 함께 지내는 사람

| 인물 | 나이 / 역할 | 분위기 |
| --- | --- | --- |
| 윤하린 | 24 / 제빵사 | 밝고 잘 챙겨주지만 가까워지면 오히려 부끄러워함 |
| 차세아 | 28 / 바텐더 | 먼저 놀리고 플러팅하다 정면으로 받아치면 당황함 |
| 백유진 | 26 / 기록담당자 | 반듯하고 조심스럽지만 취향과 게임 얘기에는 진심 |
| 한서윤 | 33 / 공간 운영자 | 든든하고 다정하면서도 허당과 장난기가 있는 연상 |
| 강이솔 | 25 / 음향기사 | 말은 짧고 무심한데 행동으로 챙기는 사람 |

모두 성인입니다. 이솔만 새 도트 디자인(`assets/isol-petite.png`)을 사용합니다. 작은 성인 체형, 밝은 피부, 은보랏빛 단발로 조정했고 성격·나이·직업은 유지했습니다. 다른 네 인물의 PNG는 변경하지 않았습니다. 이전 이솔 그림도 `assets/isol.png`에 보존했습니다.

## 관계와 결말

- 다섯 명의 호감도가 각각 25에서 시작해 0~100 안에서 따로 변합니다.
- 단체 선택은 여러 사람의 호감도를 동시에 올릴 수 있습니다.
- 다른 인물을 만났다는 이유만으로 일괄 감점하지 않습니다. 일부 실제로 서운한 행동에는 영향이 있습니다.
- 기본 화면에서는 관계를 말로 표시합니다. 읽기 설정에서 숫자를 켤 수 있습니다.
- 기본 호감도 기준은 **85 이상 Best / 65 이상 Good / 40 이상 Normal / 40 미만 Bad**입니다. Best는 마지막 개인 에피소드 경험이 필요합니다. 미해결 상처가 1개면 Normal 상한, 2개면 Bad입니다. 경계를 무시하는 선택은 −12, 실제로 바로잡는 회복 선택은 +4이며 다른 인물을 만나는 행동에는 상처 판정이 없습니다.
- 우정 엔딩은 누구의 호감도가 높아도 선택할 수 있습니다.
- 선택 순서는 장면마다 다르고 새로고침하면 같은 순서를 유지합니다.

## 실행

Node.js 22 이상. 설치할 외부 npm 패키지는 없습니다.

```sh
npm run dev
```

http://localhost:3001 에서 실행됩니다. Windows PowerShell에서 npm 실행 정책 오류가 나면 `npm.cmd run dev`를 사용하세요.

```sh
npm test
npm run build
node scripts/serve.mjs --dist
```

Vercel 연결 저장소는 **YouYoungSun/girs**입니다. 기존 테트리스 저장소와 별도로 유지합니다.

| Vercel 설정 | 값 |
| --- | --- |
| Framework | Other |
| Root Directory | 저장소 루트 `./` |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| 환경변수 / DB / 서버 함수 | 없음 |

## 저장과 조작

- 선택, 장소 이동, 연락 상대 선택, 다음 장면마다 자동저장합니다.
- 수동 책갈피 3개는 자동저장과 별개입니다. 마지막 선택 직전에 저장하면 다른 고백을 확인할 수 있습니다.
- JSON 내보내기·가져오기로 다른 기기에 기록을 옮길 수 있습니다.
- 키보드 **1 / 2 / 3**: 대답 선택. **Enter**: 반응 뒤 계속하기. 자유시간·연락·최종 상대는 직접 클릭합니다. **Esc**: 대화상자 닫기.
- 글자 크기(15~23px), 밤 모드, 작은 효과음, 호감도 숫자 표시를 설정할 수 있습니다.
- 기록은 `afterglow:v2:` localStorage에만 저장됩니다. 서버로 전송하지 않습니다. 도메인을 바꾸거나 브라우저 데이터를 지우기 전에 파일로 내보내세요.
- **v1 단일 루트 기록은 자동 변환하지 않습니다.** 실제로 겪지 않은 단체 사건과 다른 사람의 호감도를 복원할 수 없기 때문입니다. 기존 `afterglow:v1:` 기록은 삭제하지 않고 그대로 보존하며 새 버전은 별도로 시작합니다. v1 파일을 가져오면 명확한 안내를 표시합니다.

## 소스

- `src/life/days.js`: 한 달의 공동 사건.
- `src/life/visits.js`: 자유시간의 개인·단체 만남.
- `src/life/messages.js`: 주별 개인 메시지.
- `src/life/finale.js`: 마지막 고백, 20개 연애 결말과 우정 결말.
- `src/engine.js`: 달력·자유시간·호감도·마지막 선택·저장 검증·회상 분기.
- `src/storage.js`: v2 기록과 엔딩 수집.
- `docs/character-prompts.json`, `docs/isol-revision.json`: 내장 image_gen 도구로 만든 이미지의 생성·수정 프롬프트.

Google Fonts 연결이 안 되면 기본 한글 글꼴로 표시합니다. 게임 진행 자체에는 외부 API나 AI 호출이 없습니다.

## 검사

자동 검사는 다섯 인물 각각의 모든 엔딩에 실제 30일 선택으로 도달하는지, 마지막에 더 낮은 호감도의 인물도 고를 수 있는지, 하루에 한 번만 자유시간을 사용하는지, 에피소드를 반복하지 않는지, 메시지·회상·저장·이전 기록 보존이 동작하는지 확인합니다. 정적 빌드와 JavaScript 구문도 검사합니다.

이미지는 직접 확인했습니다. 브라우저 미리보기는 앞선 접근 거절을 존중해 다시 시도하지 않았으며 실제 브라우저의 레이아웃·클릭 검증은 미완료입니다.

## 시나리오·엔딩 CG 개정

엔딩 전용 CG 21장(개인 20 + 우정 1)을 `assets/endings/`에 연결했습니다. 내장 image_gen으로 기존 캐릭터를 참조해 제작했으며 원본은 `docs/ending-originals/`, 프롬프트와 출처는 `docs/ending-art.json`에 보존합니다. 모음 이미지는 엔딩 스포일러를 포함합니다.

관계가 낮은 개인 만남 25종, 주별 연락, 상처·회복 선택과 고백 반응을 분기합니다. 엔딩 서가는 획득한 그림만 표시하고, 최신 획득 결과의 실제 문구를 로컬에 저장해 재열람합니다. 그림을 불러오지 못해도 엔딩 글은 계속 읽을 수 있습니다.

자세한 규칙과 검수 결과는 `docs/revision.md`, 기본 사건 목록은 `docs/story-map.json`을 참고하세요. 이미지 재변환에는 Pillow가 필요하며 게임 실행에는 추가 패키지가 필요하지 않습니다.
