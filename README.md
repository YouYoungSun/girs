# 여름의 마지막 페이지 · AFTERGLOW

해변 마을 문화공간 ‘달무리회관’의 마지막 여름을 기록하는 텍스트 연애 게임입니다. 모든 등장인물은 성인입니다.

## 플레이

- 이름 입력 후 다섯 명 중 한 사람의 이야기를 선택합니다.
- 공통편 6개 장면 → 선택한 인물의 개별편 12개 장면 → 호감도에 따른 결말로 이어집니다.
- 전체 원고: 공통 6 + 개별 60 = **66개 장면**, 선택 직후 반응 **198개**, 캐릭터별 네 가지 **총 20개 엔딩**.
- 이전 선택에 따라 뒤의 회상 문장이 달라지고, 중간 호감도에 따른 서술도 달라집니다.
- 캐릭터별 흐름은 공유하는 틀 안에서 달라집니다. 모든 선택이 별도 장편으로 갈라지는 완전한 트리 구조는 아닙니다.
- 첫 엔딩 이후에는 공통편을 기본 선택으로 통과하고 개별편에서 시작하는 옵션이 열립니다.

| 인물 | 나이 / 역할 | 이야기의 중심 |
| --- | --- | --- |
| 윤하린 | 24 / 제빵사 | 착한 사람이 되는 일과 자기가 원하는 일을 구분하기 |
| 차세아 | 28 / 바텐더 | 능숙한 농담 뒤에 있는 진심과 경계 |
| 백유진 | 26 / 기록담당자 | 정확한 기록과 불완전한 마음 사이 |
| 한서윤 | 33 / 공간 운영자 | 모두를 돌보던 사람이 자기 미래를 고르기 |
| 강이솔 | 25 / 음향기사 | 소리를 함께 듣는 일과 말없이 곁에 있는 일 |

호감도는 45에서 시작하고 0~100으로 제한됩니다. 마지막 선택 후 **85 이상 Best / 65 이상 Good / 40 이상 Normal / 40 미만 Bad**입니다. 다른 사람과 만나는 공통 장면은 해당 사람의 호감도를 바꿉니다. 화면에 표시되는 선택 순서는 장면마다 바뀌지만, 새로고침하면 같은 순서를 유지합니다.

## 실행과 검사

Node.js 22 이상. 외부 npm 패키지를 설치할 필요가 없습니다.

```sh
npm run dev
```

http://localhost:3001 에서 실행됩니다. Windows PowerShell에서 실행 정책 오류가 발생하면 `npm.cmd run dev`를 사용하세요.

```sh
npm test
npm run build
node scripts/serve.mjs --dist
```

테스트는 실제 게임 상태를 모든 장면에 통과시켜 모든 캐릭터의 네 가지 엔딩에 도달할 수 있는지, 저장 후 다시 이어지는지, 회상 분기가 달라지는지, 잘못된 저장 파일을 거부하는지 검사합니다.

## Vercel

이 프로젝트만 담은 `YouYoungSun/girs` 저장소를 Vercel에 연결합니다. 기존 테트리스 저장소와 독립적으로 배포합니다.

- Framework Preset: **Other**
- Root Directory: **저장소 루트** (이 저장소에서는 `afterglow`를 입력하지 않습니다.)
- Build Command: **npm run build**
- Output Directory: **dist**
- 환경변수, 데이터베이스, 서버 함수: 없음

빌드 설정은 `vercel.json`에 포함했습니다. 친구들과 즐기는 개인·비상업적 정적 웹사이트로 배포할 수 있습니다. Vercel 플랜의 사용량 제한은 적용됩니다.

## 저장과 조작

- 매 선택과 다음 장면에서 자동저장합니다.
- 수동 책갈피 3개는 자동저장과 별개로 유지됩니다.
- 표지로 돌아가거나 새로고침한 뒤 **이어 읽기**로 돌아올 수 있습니다.
- 새 게임은 자동저장을 교체합니다. 이전 경로를 보존하려면 먼저 수동 책갈피를 남기세요.
- 책갈피를 JSON 파일로 내보내거나 가져와 기기 사이에 옮길 수 있습니다.
- 엔딩 서가는 이 브라우저에서 실제로 발견한 엔딩의 제목과 내용을 해금합니다.
- 데이터는 `afterglow:v1:` 접두어로 localStorage에만 저장됩니다. 서버에 보내지 않습니다. 브라우저 데이터를 지우거나 도메인을 바꾸면 기록이 이어지지 않으므로 먼저 내보내세요.
- 브라우저 저장이 차단되거나 공간이 부족하면 안내 메시지를 표시합니다. 플레이는 계속할 수 있고 파일 저장을 사용할 수 있습니다.
- 키보드 **1 / 2 / 3**: 화면의 선택지. **Enter**: 반응을 읽고 다음 장면으로. **Esc**: 열린 대화상자 닫기.
- 글자 크기(15~23px), 밤 모드, 선택 효과음을 설정할 수 있습니다. 기본 효과음은 꺼져 있습니다.

## 구조와 에셋

- `src/story/`: 직접 작성한 한국어 공통편, 인물별 이야기, 조건부 문장과 20개 엔딩.
- `src/engine.js`: 점수·진행·분기·저장 검증. 화면 코드와 분리되어 있습니다.
- `src/storage.js`: 자동저장, 수동 책갈피, 엔딩 수집.
- `src/app.js`, `src/style.css`: 독서형 반응형 화면과 입력.
- `assets/`: 이 게임을 위해 built-in image_gen으로 만든 다섯 투명 PNG 도트 캐릭터.
- `docs/character-prompts.json`: 이미지 생성에 사용한 프롬프트와 캐릭터 설정.

Google Fonts가 연결되지 않으면 기본 한글 글꼴로 표시합니다. 게임 진행은 외부 API나 AI 호출에 의존하지 않습니다.

## 검증 상태

게임 규칙·모든 엔딩의 도달 가능성·직렬화·파일 유효성 검사를 포함한 자동 테스트와 정적 빌드를 수행했습니다. 도트 이미지 다섯 장은 육안으로 확인했습니다. 브라우저 미리보기 접근이 거절되어 실제 브라우저의 화면 배치 및 클릭 동작은 자동 확인하지 못했습니다.
