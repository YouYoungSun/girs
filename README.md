# 여름의 마지막 페이지 · AFTERGLOW v2.0.2

v2.0.1에서는 하린 2장 「휴무」의 문체와 감정 흐름을 시범 수정했습니다. 전후 읽기본과 독립 검수 기록은 `docs/reference-notes/harin-2-edit-review.md`에 있습니다.

앞으로 적용할 문체·인물별 말투·장면 연결 기준과 남은 작업은 [집필 지침](docs/writing-guide.md)에 정리했습니다.

성인 다섯 명과 바닷가 달무리회관에서 시작하는 일상 로맨스입니다. 기록집과 전시를 준비하며 공통 3장을 읽고, 한 사람과 약속하면 그 인물의 개인 7장으로 이어집니다.

## v2에서 달라진 흐름

- 30일 방문·연락 메뉴와 장면마다 붙던 3지선다를 없앴습니다. 여러 화면의 이야기 뒤 중요한 순간에 선택합니다.
- 한 회차의 선택은 대략 13~14회입니다. 일상, 작업, 외출, 갈등과 후속 생활을 실제 장면으로 읽습니다.
- 개인 루트 확정 뒤 타 인물의 개인 연애 루트는 닫힙니다. 다른 선택은 확정 이전 책갈피나 새 시작에서 가능합니다.
- 하린·세아·유진·서윤·이솔의 사건과 고백 시점이 다릅니다. 연애 이후와 친구로 남는 이야기를 구분합니다.
- 숫자 호감도 대신 실제 사건·약속·관계 합의로 네 결말이 갈립니다. 공통 우정까지 총 21결말입니다.
- 수식적인 장면 소제목을 없애고 장 제목과 시간·장소를 표시합니다.

## 실행

Node.js 22 이상, 외부 패키지 설치 없이 실행합니다. 이 폴더에서 실행하세요.

```sh
npm.cmd run dev
npm.cmd test
npm.cmd run build
```

로컬 주소는 http://localhost:3001 입니다. 빌드 결과는 `dist/`입니다. 기존 서버를 열어둔 경우 새로고침하면 현재 소스를 읽습니다. 배포된 웹사이트는 새 빌드 배포가 별도로 필요합니다.

## 읽기와 저장

Enter / Space 또는 다음 버튼으로 읽습니다. 선택은 숫자 키 또는 버튼으로 고릅니다. 읽은 부분 넘기기는 미독 화면과 모든 선택에서 멈춥니다. 지난 내용에는 현재까지 읽은 서술·대사·선택만 남습니다.

자동 책갈피와 수동 3개, JSON 내보내기·가져오기를 지원합니다. 화면 위치와 선택의 결과를 복원합니다. 저장 파일을 읽을 때 처음부터 실제 선택을 재생해 현재 위치·루트·사건 기억을 검증합니다.

v2 저장은 `afterglow:release-v2:` 영역을 사용합니다. 기존 `afterglow:release-v1:` 저장은 변경하거나 삭제하지 않습니다. v1 진행을 새 이야기로 변환하지 않으며, 책갈피 메뉴에서 v1 보관본 전체를 내보낼 수 있습니다. 이름과 글자 크기·야간 설정만 초기값으로 재사용합니다. v1 엔딩 수집은 v2에 합산하지 않습니다. v1 설명서는 `docs/README-v1.md`에 보존했습니다.

상단 버전 표시는 `package.json`에서 읽습니다. 새 버전이 감지되면 새로고침을 안내하고 진행을 강제로 끊지 않습니다. 저장 스키마와 출시 버전은 별개입니다.

## 검증과 집필 자료

- 설계: `docs/v2-story-plan.md`
- 재개·검증 상태: `docs/v2-status.md`
- 실제 경로 분량·선택 목록: `docs/v2-path-audit.json`
- 원고: `src/v2/common.js`, `routes-a.js`, `routes-b.js`, `routes-c.js`
- 분기 감사: `node scripts/v2-audit.mjs`
- 경로 읽기: `node scripts/v2-readthrough.mjs harin best`

60~90분은 목표입니다. 글자 수·자동화 진행 시간을 사람의 실독 시간으로 취급하지 않습니다. 실제 독해 속도에 따른 체감 플레이 시간과 화면 검증의 완료 여부는 상태 문서를 확인하세요.

기존 픽셀 캐릭터와 엔딩 CG 21장을 재사용합니다. 원본 이미지는 보존했습니다. v1 소스도 남겨두었지만 기본 진입점은 v2입니다.
